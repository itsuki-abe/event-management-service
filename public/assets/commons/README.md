# Workshop Commons assets

Generated with built-in ImageGen using the selected community-commons.png design as the visual reference.

- collaboration.png: four people collaborating around a table, flat navy/blue/apricot/yellow illustration, transparent background; used on Home and Team.
- avatar-misaki.png: navy-haired speaker, peach top, pale-blue circle, transparent outside; used for the current speaker.
- avatar-ken.png: short navy-haired speaker, blue shirt, pale-blue circle, transparent outside; used for the next speaker and sample members.

UI layout, panels and typography are CSS. Standard icons in ../icons are generated from Phosphor Icons (MIT) by scripts/generate-commons-icons.mjs. Zen Maru Gothic is bundled from @fontsource/zen-maru-gothic (OFL-1.1). QR codes are generated from the actual participant URL with qrcode.react.
