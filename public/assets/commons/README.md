# Workshop Commons generated assets

Generated with built-in ImageGen using the selected community-commons.png design as the visual reference.

- collaboration.png: four people collaborating around a table; transparent flat navy/blue/apricot/yellow illustration. Used by Dashboard and TeamPage.
- avatar-misaki.png and avatar-ken.png: decorative illustrated avatars. SpeakerAvatar chooses a stable variant without storing participant photos. The actual speaker name remains adjacent text.

Layout, typography and panels are CSS. Zen Maru Gothic and Material Symbols are self-hosted with Fontsource; workspace icons use lucide-react; QR codes use qrcode.react.
