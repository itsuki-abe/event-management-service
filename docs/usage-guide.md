# ログイン後の使い方ガイド

`/help` で、運営・参加者それぞれの操作手順を確認できます。ログイン中の役割を確認して案内し、画面上部の「使い方」とページ下部のリンクからいつでも戻れます。`eventId` を指定すると、そのイベントの会場案内・参加登録・コメント管理へのリンクになります。

- 運営用リンクでのログインに成功すると、運営のガイドへ移動します。イベント未作成時は作成手順から始まります。
- 通常の参加登録に成功すると、参加者のガイドへ移動します。プロフィールの編集・再読み込みでは移動しません。
- PC接続用QRからの参加登録では、接続確認を優先して参加ページに留まります。接続後は「使い方」からガイドを確認できます。
- 役割の切り替えは説明の切り替えです。運営向け手順には運営ログイン、参加者向け手順には対象イベントの参加登録が必要です。

手順には操作ボタン名、完了後の状態、各画面へのリンクを掲載しています。会場の設定、参加用QR、発表の登録・進行、画面共有、リアクション・コメント、参加者検索、PC接続、困ったときの対処を案内します。

LT進行・発表者画面・会場スクリーンは、既存の実装に合わせて最初のイベントが対象です。会場案内・参加登録・参加者一覧・コメント管理はイベントIDを引き継ぎます。

## 実装と検証

- `src/components/usage-guide.tsx`：状態表示、役割切り替え、手順、FAQ。
- `src/lib/usage-guide.ts`：役割別の操作説明。
- `src/components/screen-sharing-guide.tsx`：発表者と運営の画面共有手順。
- `src/server/help.ts`：既存Cookieを使った権限・参加状態の読み取り。セッションを新規作成しません。
- `src/server/help.test.js`：権限、イベント分離、期限切れ、空DB、エラー時の検証。
- `scripts/usage-guide-browser.mjs`：隔離D1を使うログイン・参加登録・再試行・ペアリング・画面幅・キーボード操作の検証。

```sh
bun run typecheck
bun run check
bun test
bun run build
node scripts/usage-guide-browser.mjs
```

ブラウザー検証はビルド済みのWorkerを起動し、専用の一時DBだけを変更します。画面の記録は `output/usage-guide-qa/` に出力します。
